# ميثاق | MITHAQ

منصة مستقلة للتعارف الجاد بقصد الزواج المعلن أو زواج المسيار، مع احترام الخصوصية ورضا الطرفين وحماية البيانات.

## حالة المشروع
المشروع في مرحلة التأسيس وبناء النموذج الأولي. المستودع خاص. لا يوجد حتى الآن تطبيق إنتاجي أو خدمة تسجيل أو قاعدة بيانات حقيقية.

## المبادئ الأساسية
- لا تُكشف وسيلة واتساب إلا بعد موافقة صريحة ومنفصلة من الطرفين.
- لا محادثات داخلية في التصور الأساسي؛ التواصل الخارجي عبر واتساب بعد الموافقة.
- لا صور أو فيديوهات في المنتج المقترح.
- قسم «حياتي» نص فقط وفق الضوابط الموضحة في وثيقة المتطلبات.
- لا رسوم على التواصل الأساسي، ولا بيع للبيانات أو الموافقات.
- ميثاق وسيط تقني مستقل وليس جهة حكومية أو جهة عقد زواج.

## محتويات المستودع
- `docs/PRODUCT_SPEC.md` — المتطلبات الأولية.
- `docs/SECURITY_PRIVACY.md` — مبادئ الخصوصية والموافقة والأمن.
- `docs/ROADMAP.md` — مراحل التنفيذ.
- `prototype/index.html` — نموذج واجهات ثابت للتجربة فقط.

## تجربة النموذج الأولي
افتح `prototype/index.html` في متصفح. النموذج لا يحفظ بيانات ولا ينشئ حسابات ولا يرسل واتساب. استخدم بيانات وهمية فقط.

## تنبيه
هذه الوثائق لا تغني عن مراجعة قانونية وأمنية محلية قبل جمع أي بيانات حقيقية أو إطلاق الخدمة.
